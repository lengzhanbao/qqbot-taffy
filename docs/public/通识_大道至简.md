# 通识：大道至简

## 第一原则

先完整，再风格。

回答不能只剩半个实体、半句话、半段正文。风格只是表达层，不能替代事实层。

## 固定判断

1. 有来源：按来源答，实体、数字、日期逐字保真。
2. 没来源：明说“塔菲没查到”，不用训练记忆猜。
3. 缺字段：先重答；重答仍缺，就把来源里能确认的字段补上。
4. 模型被截断：丢弃，不把半句发给用户。
5. 专名：必须完整，不缩写、不拆开、不漏字。

## 已去除的残断点

- 页面正文硬截 `6000`，改为 `QQ_MAX_PAGE_TEXT_CHARS`，默认 `12000`。
- 歌词上下文硬截 `18000`，改为 `QQ_MAX_LYRIC_CONTEXT_CHARS`，默认 `24000`。
- 搜索摘要按 `QQ_SEARCH_SNIPPET_CHARS` / `QQ_SEARCH_DISTILL_CHARS` 控制，不藏死值。
- `finish_reason=length` 的模型输出会直接丢弃，不发送。
- 实体校验不再拆出 `克王 / 国世 / TikT / ok` 这类碎片。
- 数字校验不再只看“回答里有没有数字”，而是核对来源里的具体值。

## 禁止

- 禁止每题单独补一条事实来掩盖系统问题。
- 禁止为了“更像塔菲”丢数字、丢专名、丢字段。
- 禁止在来源没有答案时用“我猜 / 大概是”填具体事实。
- 禁止把工具调用 JSON、搜索计划、占位话术当最终回答。
- 禁止让已经残缺的历史回答继续进入上下文。

## 污染数据原则

发现污染数据必须改正，不能继续传播。

1. 先检测：书名号不齐、专名缺前缺后、类型词缺字、工具 JSON 残留。
2. 再修正：能补全就补全，不能补全就用可靠兜底。
3. 最后隔离：读取历史/记忆时，把污染内容替换成干净内容，不让模型继续模仿。

不能因为“这是旧回答”就原样送进模型上下文。

## 落地位置

- 主要逻辑：`bridge_qq.py`
- 答案契约：`_answer_contract_missing`
- 字段补全：`_complete_missing_fields`
- 数字保真：`_ensure_numeric_facts_preserved`
- 歌词正文：`_extract_lyrics_block`
